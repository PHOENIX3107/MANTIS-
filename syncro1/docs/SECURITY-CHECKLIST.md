# Security checklist

- [x] Self-signup and anonymous login are disabled.
- [x] Allowed email domains are configured and protected by a pre-mutation
      event plus the CLI audit.
- [x] The bootstrap disables `administrator` and `root` and locks `admin/`.
- [x] Crypto salt is environment-provided and stable; it is not generated by
      deploy scripts.
- [x] Uploads use DISK storage outside the web root, with an extension allow-list
      and deny-list.
- [x] PHP, nginx, and Mantis receive the same upload-size setting.
- [x] Nginx denies sensitive directories, SOAP/REST/RSS paths, dotfiles, logs,
      SQL, and Composer metadata; login and lost-password endpoints are rate
      limited.
- [x] `nosniff`, referrer, frame, and CSP headers are present.
- [x] PHP errors are logged, not displayed; OPcache and strict session settings
      are enabled.
- [x] RDS is private and only the EC2 security group can reach port 3306.
- [x] EC2 requires IMDSv2 and uses SSM instead of SSH.
- [ ] Production TLS, SES production access, WAF, malware scanning, and SSO
      require operator setup.

The CSP retains `unsafe-inline`/`unsafe-eval` for Mantis 2.28.4 UI compatibility;
verify a stricter policy during a browser-based staging review before tightening
it.
